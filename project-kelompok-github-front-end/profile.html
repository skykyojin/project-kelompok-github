Bantuan & FAQ Pages

Bagaimana cara membaca buku?

Buka halaman Beranda atau Rak Saya, klik pada sampul buku pilihan kamu, lalu tekan tombol "Lanjut Membaca".

Bagaimana cara menambahkan buku ke Favorit?

Klik tombol ikon tanda kurung/bookmark di kartu buku atau halaman detail untuk menyimpannya ke daftar favorit.

Apakah aplikasi ini terkoneksi ke Supabase?

Ya, seluruh data koleksi buku dan bab terhubung langsung ke database Supabase Cloud.
